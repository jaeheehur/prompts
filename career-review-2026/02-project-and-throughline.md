# 요청: 2026년 내 프로젝트 이력 정리

## 배경
나는 LG화학 [팀명]에서 AX(AI 전환) 업무를 하고 있다. 올해 한 프로젝트를 빠짐없이 정리해서
(1) 내년 과제 로드맵을 세우고 (2) 커리어 방향을 정하고 (3) 이력서·경력기술서에 쓸 근거 자료를 만들려고 한다.
정리 기간은 2026년 1월 1일부터 오늘까지다.

## 참고할 자료
네가 접근할 수 있는 자료를 모두 찾아봐라: [메일, 결재 문서, 보고서, 회의록, 코드 저장소, 배포 공지, 메신저 등].
아래는 내가 기억하는 프로젝트다. 이 목록은 시작점일 뿐이니, 빠진 프로젝트가 있으면 찾아서 추가해라.
- 기업 기술 분석 Agent: 경쟁사를 입력하면 기본 정보, 보유 특허, IP 포트폴리오, 전략을 분석
- IP Intelligence팀 AX 멘토링: MCP 연결, 특허 분석 코드
- 액상 전구체 문헌 분석 및 DB 구축 (1~6월): 논문·특허 추출, 요약·분석, 물질 DB와 연결해 실험 정보 추출
- 람노리피드 특허 분석 (기술협력팀): 고객사 대응, 평균 2주 걸리던 작업을 하루 만에 처리
- PPT Generator
- 전사 공지로 배포한 에이전트들, AX-Fair 제출 과제, AX Roadmap 참여 과제
- [그 외 기억나는 것]

## 프로젝트별로 정리할 항목
프로젝트마다 아래 항목을 채워라. 자료에서 확인되지 않는 항목은 비워 두지 말고 "확인 필요"라고 적어라.
1. 프로젝트명 / 기간 (시작~종료, 진행 중이면 현재 상태)
2. 요청 부서와 실제 사용자: 누가 왜 요청했나
3. 해결하려던 문제: 도입 전에 어떤 업무가 어떻게 오래 걸리거나 어려웠나
4. 내 역할: 기획, 개발, 데이터 구축, 교육 중 무엇을 했나. 혼자 했는지, 팀 안에서 내 기여 비중은 얼마였나
5. 접근 방법과 기술: 사용한 모델, 에이전트 구조, MCP·도구 연동, 데이터 소스, DB 설계 등
6. 산출물: 배포된 서비스, 보고서, DB, 교육 자료 등
7. 성과: 가능하면 숫자로 적어라 (소요 시간 전후 비교, 사용자 수, 처리 건수, 비용, 후속 요청 등).
   각 숫자에 출처를 달고, 자료로 확인한 숫자인지 추정한 숫자인지 구분해라.
8. 근거 자료: 판단의 근거가 된 문서명이나 링크

## 커리어 줄기 분석
프로젝트 정리가 끝나면 아래를 분석해라.
1. 프로젝트들을 성격이 비슷한 것끼리 묶고, 묶음마다 이름을 붙여라.
2. 내 가설은 "올해 한 일의 중심은 특허·논문 같은 기술 문서 분석 시간을 줄이는 AX"라는 것이다.
   이 가설이 자료로 뒷받침되는지 검증해라. 맞지 않거나 다른 줄기가 더 뚜렷하다면 그렇다고 말해라.
   내 가설에 억지로 맞추지 마라.
3. 프로젝트들에서 반복해서 드러나는 내 역량을 정리하고, 각 역량을 뒷받침하는 프로젝트를 연결해라.
4. 내년에 이 줄기를 키우려면 무엇이 비어 있는지 짚어라
   (예: 정량 성과가 부족한 과제, 일회성으로 끝난 과제, 확장할 수 있는 과제).
   특히 IP그룹 대상 AX(특허 분석, 경쟁사 특허 전략, 선제적 특허 출원 지원, 계약 시 침해 리스크 점검)와 이어지는 지점을 찾아라.

## 출력 형식
1. 전체 요약 (5줄 이내)
2. 프로젝트 목록 표: 프로젝트명, 기간, 요청 부서, 내 역할, 핵심 성과
3. 프로젝트별 상세 (위 8개 항목)
4. 커리어 줄기 분석
5. 경력기술서용 문장: 프로젝트마다 "문제 → 내가 한 일 → 결과" 형식의 1~2문장
6. 확인 필요 목록: 내가 직접 채워야 할 정보

## 주의사항
- 자료에 없는 사실이나 숫자를 지어내지 마라. 모르면 "확인 필요"라고 써라.
- 경력기술서용 문장은 외부에 공유할 수 있게 써라. 고객사 이름, 내부 시스템 이름, 기밀 수치는
  일반적인 표현으로 바꿔라 (예: "글로벌 IT 고객사", "사내 물질 DB").
- 프로젝트를 빠뜨리는 것보다 많이 찾는 편이 낫다. 애매한 건 포함하고 "애매함"이라고 표시해라.
