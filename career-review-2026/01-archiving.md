# 요청: 2026년 내 업무 전체 아카이빙

## 목적
올해 내가 한 모든 업무를 빠짐없이, 최대한 자세하게 기록으로 남기려고 한다.
이번 요청의 목적은 '해석'이 아니라 '수집'이다. 중요해 보이는지와 상관없이 전부 찾아서 정리해라.
작은 요청 대응, 중간에 중단된 과제, 교육, 행사, 다른 팀 지원도 모두 포함한다.
정리 기간은 2026년 1월 1일부터 오늘까지다.

## 찾는 방법
1. 접근할 수 있는 자료를 모두 확인해라: [메일, 결재 문서, 보고서, 회의록, 코드 저장소, 배포 공지, 메신저, 일정 등]
2. 1월부터 지금까지 월별로 훑어라. 달마다 무슨 일을 했는지 확인하면 빠지는 과제가 줄어든다.
3. 아래 유형을 하나씩 따로 찾아라. 유형마다 최소 한 번은 검색해라.
   - 직접 개발한 에이전트·서비스·도구
   - 데이터 수집, DB 구축, 분석 업무
   - 다른 부서의 요청에 대응한 일 (일회성 포함)
   - 교육, 멘토링, 발표, 사내 행사 (AX-Fair 등)
   - 전략·기획 업무 (로드맵, 과제 발굴, 보고서 작성)
   - 팀 내부 업무 (운영, 프로세스 개선, 협업 지원)
   - 시작했지만 중단되었거나 보류된 과제
4. 내가 기억하는 프로젝트 일부를 적어 둔다. 이 목록은 전체의 일부일 뿐이고 대표성도 없다.
   여기 있는 것과 비슷한 과제만 찾지 말고, 위 유형 전체를 고르게 찾아라.
   - 기업 기술 분석 Agent / IP Intelligence팀 AX 멘토링 / 액상 전구체 문헌 DB 구축
   - 람노리피드 특허 분석 / PPT Generator / 전사 배포 에이전트들 / AX-Fair / AX Roadmap
   - [그 외 기억나는 것]

## 업무별 기록 항목
업무마다 아래 항목을 채워라. 작은 업무도 같은 항목으로 기록하고, 모르는 항목은 "확인 필요"라고 적어라.
1. 업무명 / 기간 / 현재 상태 (완료, 진행 중, 중단, 보류)
2. 유형 (위 7가지 중 하나)
3. 요청자 또는 협업 부서, 실제 사용자
4. 배경: 왜 시작했나, 도입 전에는 어떻게 일했나
5. 내 역할과 기여 비중: 무엇을 직접 했나
6. 진행 과정: 주요 단계, 부딪힌 문제와 해결 방법, 방향이 바뀐 지점
7. 사용한 기술과 데이터: 모델, 에이전트 구조, 연동한 도구, 데이터 소스
8. 산출물
9. 결과와 반응: 숫자가 있으면 출처와 함께 적고, 확인한 숫자인지 추정한 숫자인지 구분해라.
   사용자 피드백, 후속 요청, 보고 여부도 적어라.
10. 근거 자료: 문서명, 날짜, 링크

## 출력 형식
1. 월별 타임라인: 달마다 한 일을 한 줄씩
2. 전체 업무 목록 표: 업무명, 기간, 유형, 상태, 내 역할
3. 업무별 상세 기록 (위 10개 항목)
4. 확인 필요 목록: 내가 직접 채워야 할 정보
5. 찾아본 자료 범위: 어떤 자료를 확인했고, 어떤 자료는 접근하지 못했는지

## 주의사항
- 업무의 중요도를 판단하거나 순위를 매기지 마라. 모든 업무를 같은 깊이로 기록해라.
- 업무들을 하나의 주제로 묶거나 커리어 방향을 해석하지 마라. 그건 다음 단계에서 따로 한다.
- 자료에 없는 사실이나 숫자를 지어내지 마라.
- 너무 많다 싶어도 줄이지 마라. 빠뜨리는 것보다 많이 남기는 편이 낫다.
